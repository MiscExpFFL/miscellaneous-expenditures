MISCELLANEOUS EXPENDITURES — 2026 WEEKLY UPDATE GUIDE

NORMAL 2026 WORKFLOW
1. Run the MEFFL Tampermonkey collector after MNF in POST-MNF mode.
2. Set Upcoming Week to the week about to be played.
3. AUTO COLLECT LEAGUE and confirm the checks are green.
4. Export the JSON and send it with the latest cumulative site build.
5. After waivers process, repeat in POST-WAIVERS mode for the same Upcoming Week.

SITE IMPORT
Run locally from the site root if needed:

  python tools/apply-weekly-export.py MEFFL_2026_W02_POST_MNF.json .

The site loads:
season-2026.js -> weekly-import.js -> me-weekly-sync.js -> me-engine.js

The stable season/history sources stay intact. Collector snapshots overlay factual Yahoo data before the live engine calculates the current pages.

SAFETY
- Only completed validated games may enter results/history/records/H2H.
- Upcoming Yahoo projections never become standings or historical scores.
- POST-WAIVERS cannot erase a previously archived POST-MNF snapshot.
- The deployable weekly-snapshots archive is SANITIZED. Raw Yahoo page captures/sourceText and signed-in account text are not copied into the public site build.
- Keep the original downloaded collector JSON private; it may contain raw text Yahoo displayed in your logged-in browser.
- Never put Yahoo passwords, OAuth secrets, access tokens or refresh tokens in the public site.

DEPLOYMENT
Upload the full cumulative build to the existing GitHub Pages site. Do not change GoDaddy DNS, the GitHub Pages custom domain, or HTTPS settings.
